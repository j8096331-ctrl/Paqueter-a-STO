# Paquetería "Sto. Tomás"

Sistema de notas, envíos, cobros y entregas México ⇄ Estados Unidos.

- Notas en serie **01 MX** (México → EE. UU.) y **001 EU** (EE. UU. → México).
- Registro e historial de cada persona, faltantes por reponer (aduana, pérdida, daño).
- Impresión térmica 2 × 4 pulg (nota y etiquetas de bolsa), tickets 58/80 mm, hoja carta.
- Nota como imagen por WhatsApp, entregas con firma, viajes con manifiesto.
- Funciona en computadora, tablet y celular, también sin internet (se instala como app).

Los datos se guardan en cada equipo. Para pasar información entre sucursales: **Ajustes → Descargar respaldo** y en el otro equipo **Importar y combinar**.

Las versiones anteriores están en la carpeta `anterior/`. Sus datos se pasan solos al sistema nuevo la primera vez que se abre en el mismo navegador.
